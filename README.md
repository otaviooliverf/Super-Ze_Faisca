# Super Zé-Faísca

Jogo em HTML/CSS/JavaScript.

## Estrutura

Os arquivos do jogo estão na pasta `Super Zé-Faísca/`:

- `ze_faisca_super.html` — página principal do jogo
- `estilos.css` — estilos
- `jogo.js` — lógica do jogo
- `gerador_de_sprites.html` — ferramenta para gerar sprites
- imagens `.png` / `.jfif` — sprites e artes

## Como rodar

Abra `Super Zé-Faísca/ze_faisca_super.html` no navegador.
